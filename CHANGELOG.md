# Changelog

Every change that reaches a user lands under **Unreleased** in the pull request that makes it.
A release moves that section under its tag with the date, and the release notes are that section.

## Unreleased

- A refusal across the JNI boundary is always a refusal. The layer looks its exception class up by name, so a build that renames or strips it found nothing and handed back a null where the binding declares a non-null array; the caller then saw a null pointer exception carrying nothing about why the call was refused.
- Nothing is handed back as nothing. An empty answer used to carry an aligned sentinel pointer rather than no address, and a web host that built a view at that offset threw on every page load, on a deployment that had simply revoked nobody.
- The Apple slices and the xcframework a Swift consumer resolves, so an app takes the engine with no Zig and no build step of its own.
- The Go SDK, for the api that issues and revokes: a fifth implementation of the same bytes rather than a cgo binding, held to the engine by replaying every frozen vector through it.
- The engine behind the checkmark: the four credential kinds, the signed preimage they share, and the offline walk from a staff badge through its organization's capability to a Goss root key. Scope is enforced by the credential rather than promised, so an organization approved for one category cannot issue for another, and pulling one capability invalidates every badge that flowed from it at once.
