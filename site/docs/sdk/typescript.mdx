```ts
import { Mark, Kind, Status } from '@myzonerocks/gossmark'
```

## Keys and signing

```ts
const pub = await Mark.publicKey(seed)
const signed = await Mark.sign(seed, preimage)
```

## Verifying

```ts
const badge = await Mark.verifyDirect(signed, roots, revoked, now)
const staffBadge = await Mark.verifyStaff(staff, capability, roots, revoked, now)
```

Calls are async because the wasm module loads on first use.

## What you get back

```ts
export interface Badge {
  kind: number
  subject: Subject
  category: string
  issuedAt: number
  expiresAt: number
  issuer: Uint8Array
  via?: Subject
}

export interface Subject {
  chain: bigint
  address: Uint8Array
}
```

## Revocation

```ts
const snapshot = await Mark.signSnapshot(seed, seq, issuedAt, ids)
const opened = await Mark.openSnapshot(snapshot, roots, heldSeq)
```

## Errors

Calls reject with `MarkError`, which carries the status the core returned.

## Bytes, not strings

Everything crosses as `Uint8Array`. Converting through base64 or hex at the
boundary costs more than passing the bytes you already have, so keep them in
their binary form until you render.
